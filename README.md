# LegacyGuard

**数字遗产与账号托管平台**

人一生中会积累大量数字资产：社交账号、云盘、加密货币钱包、订阅服务、域名与服务器。当一个人离开后，这些账号往往无人知晓、无法访问，或者因平台自动注销而永久消失。

LegacyGuard 的目标是让数字资产可以被**有序地交接**，而不是随人一起消失。

## 规划中的核心能力

| 能力 | 说明 |
| --- | --- |
| 资产清单 | 统一登记账号、资产类别、所在平台与处置意愿 |
| 继承规则 | 指定继承人、分配比例、按类别设置不同的处置方式 |
| 触发机制 | 基于失联检测（定期签到）与多见证人确认的激活流程 |
| 安全交接 | 凭证加密封存，仅在触发条件满足后对指定继承人解密 |
| 审计留痕 | 每一次访问、变更、激活操作均不可篡改地记录 |

## 安全原则

这个项目处理的是最敏感的一类数据，因此以下原则不可妥协：

- **零明文**：平台不应持有任何可读的用户凭证，密钥只在客户端或专用加解密通道中短暂存在
- **最小暴露**：继承人只能拿到被明确分配给自己的那一份，而非全部
- **可验证触发**：激活流程必须有多重独立确认，防止单人误判或恶意触发
- **隐私优先**：资产清单本身即是高价值情报，默认加密存储
