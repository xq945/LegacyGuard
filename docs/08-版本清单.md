## 8.4 三个需要特别注意的版本细节

### ① MyBatis-Plus 必须用 boot3 starter

```xml
<artifactId>mybatis-plus-spring-boot3-starter</artifactId>
```

用老的 `mybatis-plus-boot-starter` 会在启动时报 `javax.*` 相关类找不到 ——
Spring Boot 3 全面迁移到 `jakarta.*` 命名空间，而老 starter 仍编译在 `javax` 上。

### ② 分页插件依赖独立的 jsqlparser 模块

MyBatis-Plus 3.5.9 起，`PaginationInnerInterceptor` 依赖的 jsqlparser 被拆出为
`mybatis-plus-jsqlparser`。只引 starter 不引它，**分页在运行期才会报错**
（`ClassNotFoundException: net.sf.jsqlparser...`），编译期完全正常，容易在联调时才发现。

### ③ jjwt 停在 0.12.6 而非 0.13.0

0.13.0 发布较新，API 存在变动。本项目用到的 `Jwts.builder()` / `Jwts.parser().verifyWith()`
在 0.12.x 上有充分验证；升级需单独回归，不在第二阶段范围内。

## 8.5 复现验证

```bash
cd backend

# 1. 编译
mvn -B -DskipTests compile

# 2. 单元测试
mvn -B test

# 3. 查看实际解析的依赖版本
mvn -B dependency:list -DoutputFile=target/deps.txt -DincludeScope=compile
grep -iE "spring-boot:|mybatis|springdoc|jjwt" target/deps.txt
```

当前结果：编译通过，9 个单元测试全部通过（见 [09-第二阶段说明](09-第二阶段说明.md)）。
